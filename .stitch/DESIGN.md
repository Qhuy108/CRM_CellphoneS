# CellphoneS CRM Design System (Frappe Desk v15)

## 1. Brand & Theme Guidelines
- **Primary Color:** `#D70018` (CellphoneS Signature Red)
- **Primary Dark / Hover:** `#B30012`
- **Secondary / VIP Gold:** `#F59E0B` (Smember Gold Badge & Accents)
- **Success / On-Time:** `#10B981` (SLA Passed, Ticket Closed, Converted)
- **Warning / Pending:** `#F59E0B` (In Progress, Pending Vendor)
- **Danger / SLA Breach:** `#EF4444` (SLA Breached, Critical Priority)
- **Neutral Dark (Text & Sidebar):** `#1F2937` / `#111827`
- **Neutral Background (Canvas):** `#F8FAFC`
- **Card Background:** `#FFFFFF`
- **Border Color:** `#E2E8F0`

## 2. Typography
- **Font Family:** `Inter`, `Roboto`, system-ui, -apple-system, sans-serif
- **Headings:** 600 / 700 Semi-Bold / Bold
- **Body Text:** 400 Regular / 500 Medium
- **Numbers & Codes:** `JetBrains Mono` or Monospace for IMEI, SKU, Ticket IDs (`TCK-2026-XXXXX`), Customer IDs (`CUST-2026-XXXXX`).

## 3. Component Standards (Frappe Desk v15)
- **Border Radius:** `8px` (Cards, Inputs, Buttons, Modals)
- **Sidebar:** Width `260px`, dark/light slate theme with CellphoneS branding, CRM Module items (Khách hàng, Nhu cầu tư vấn, Tương tác đa kênh, Phiếu hỗ trợ, Dashboard & Báo cáo).
- **Topbar:** Awesome Bar (Global search for IMEI, Phone, Ticket), SLA Breach Live Alert badge, User Profile & Role switcher.
- **Form Layout:** Tabbed Header, Status Pills, Action Button Bar, Key Information Grid, Child Tables with inline add/edit.
- **Kanban Board:** 5 Swimlanes (`Open` -> `In Progress` -> `Pending Vendor` -> `Resolved` -> `Closed`) with SLA countdown clocks and priority tags.
